# Раздел «Язык C#» — исходники статей

Markdown-тела статей трека `.NET Backend` → раздела `csharp-lang`.
Здесь только текст: заголовок, анонс и грейд перечислены ниже, потому что
в базе они лежат отдельными полями, а не во фронтматтере.

## Зачем файлы, если статьи в БД

Копия на случай потери базы и источник для переноса в другую среду.
**Источник правды — база:** правки делаются через админку
(`/admin/theory`), а не здесь. Если правите файл — перенесите изменение
в админку руками, иначе они разойдутся.

Автоматического импорта нет намеренно: сидер, который бы заливал эти файлы
при старте, конфликтовал бы с правками из админки — два источника правды
на один текст.

## Как перенести в другую среду

Через админку: `/admin/theory` → трек → раздел → «+» на строке раздела,
затем вставить тело из файла и заполнить поля из таблицы выше.

Прямой SQL в боевую базу не нужен и хуже: `ReadingMinutes` придётся считать
самому, а кэш публичного дерева не сбросится — правка доедет до сайта
только через 15 минут.
